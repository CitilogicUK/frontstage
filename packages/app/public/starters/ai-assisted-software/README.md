# AI-assisted software

Use this starter when a coding agent helps build the software and the finished app does not call an AI model.

1. Copy `AGENTS.md` and `CLAUDE.md` into your repository root. Claude Code imports the shared instructions from `AGENTS.md`.
2. Complete the included `PROJECT_BRIEF.md` with the intended users, data and integrations, delivery stage, and what would count as success. Show it to the coding agent before it begins.
3. Customize `catalog-info.yaml` and register it in Frontstage if the app belongs in your inventory. Set the real owner, team, purpose, source URL, and data and audience classifications.
4. Update the delivery stage and review requirements before opening the app to a wider audience or production data.

The starter has no runtime model dependency and requires no gateway key.
